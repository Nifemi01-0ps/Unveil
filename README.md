# Story Behind The Art

A storytelling-first art discovery platform where collectors experience the journey behind artworks through immersive narratives.

## Vision

Every artwork has a story behind it.

## Core Features

- Artist onboarding
- Collector onboarding
- Discovery feed
- Chapter-based storytelling
- Artwork reveal
- Own This Journey experience

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Walrus Storage
- Tatrum Api


## Design Principles

- Mobile first
- Accessible
- Performance focused
- Storytelling centered
